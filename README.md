# 📝 To-Do List App

A clean, modern, responsive To-Do List web application built using
**HTML**, **CSS**, and **JavaScript**.\
This app includes add/edit/delete features, completion tracking,
localStorage, counters, and a polished UI.

## 🚀 Features

-   Add tasks
-   Edit tasks
-   Delete tasks
-   Mark tasks as completed
-   LocalStorage persistence
-   Total & completed counters
-   Custom popup warning
-   Fully responsive design
-   Modern UI with glassmorphism

## 🧠 How It Works

Tasks are saved using localStorage:

    localStorage.setItem("tasks", tasks.innerHTML);

Counters are updated by counting `<li>` elements.
